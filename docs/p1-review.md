# P1 独立レビューと修正記録

初回の対象はMain `dbb3576` から `f9640c1` までのブランチ全体です。
別コンテキストで仕様、実装、テスト、文書、通知原文を確認し、重要4件・軽微4件を指摘しました。
重大な指摘はありません。以下は指摘を受けて追加した修正です。
最終再レビューと全体検証の結果は、確認後に追記します。

| 指摘 | 修正と回帰確認 |
| --- | --- |
| 古いグラフ追加応答が同じ辞書の新しい表示へ混ざる | 言語・revision・imports/data世代・表示上限を含む表示識別子で成功・失敗・後処理を判定。遅延した近傍／結果ノードの応答を再現。 |
| 参照のみ／定義済みの判定が古いまま残る | 現在の一覧から判定を更新。タブを離れている間の構造変更も識別し、Undoで存在し続ける選択は維持。新しい構造のページにない古い選択は解除。 |
| 遅いクエリ項目選択が別辞書や別クエリへ入る | 辞書の表示識別子とクエリ操作の世代で判定。辞書切替、テキスト化、保存済みクエリ読込、クリア後の応答を再現。 |
| 前の辞書のimports完了通知が現在の件数を変える | 親への通知を辞書を開いた単位に限定。同じ辞書のタブを離れただけなら、成功／部分失敗の更新は反映。 |
| 巨大な制約件数の拒否説明が丸められる／例外になる | SHACLと既存TurtleのOWL件数の双方で、JavaScript安全整数を超える値を文字列として保持。`2**53+1` と `10**400` をAPIで再現し、原文・拒否応答・RDF不変を確認。 |
| クエリ作成の案内が英語のまま残る | 型なし／接続なしの案内をコードと元の名称で保持し、現在のUI言語で表示。名称にHTML風文字・波括弧があっても文字列のまま保持。 |
| 出典の日付・サンプル説明が日本語UIでも英語になる | プロジェクトカードと検証結果で現在のlocaleを渡す。ファイル名を保持した日英切替を確認。 |
| 削除プレビューのエラーが翻訳用情報を無視する | 共通のエラー表示を使い、原文は詳細欄に保持。言語切替でプレビューや削除を再実行しない。 |
