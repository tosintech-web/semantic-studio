# 日本語辞書ワークスペースの使い方（P1）

P1はローカルで辞書を閲覧・編集する段階です。Google Workspace認証とチームでの
同時利用はP2で実装する計画です。チーム用のログイン画面や権限制御はまだ追加していません。

## 辞書を開く

ホームの各カードが1つの辞書です。「項目一覧」で全項目、「探索」でグラフと検索を開けます。
RDFファイルは「読み込み」から選びます。成功したファイルが開き、通知に名前が表示されます。
失敗したときは、それまで開いていた辞書を保持します。

公開試験用の合成辞書は、READMEの生成コマンドで一時フォルダに作れます。
架空組織3,035件に、意味の異なる2つの「犬」、ラベルだけの項目、長い名称などを加えています。
既存の日本語WordNetデータを使う場合の出典・条件確認と全件対応はP4の範囲です。

## 言語を選ぶ

- **UIの言語**：画面の説明・ボタン・警告を日本語／英語に切り替えます。初期値は日本語です。
- **辞書の表示言語**：名称・説明を読む言語です。ライブラリでは言語タグを入力して適用します。
  明示的な選択を辞書ごとにブラウザへ保存します。未選択の場合はUIの言語を優先します。
- **プロジェクトの主言語**：辞書の編集規則に使う設定です。UIや表示言語を切り替えても変わりません。
  プロジェクトの表示言語はヘッダーの「…」にある言語設定で選びます。

希望する言語の名称がない場合は代替の名称を表示し、一覧で実際の言語を確認できます。
別名は検索に使いますが、表示名として自動で置き換えません。

## 項目を探す

探索の検索は1文字から使えます。日本語IMEの変換中は検索せず、確定後300ミリ秒待って
候補を取得します。候補は最大25件です。上下キーで候補を選び、Enterで詳細を開けます。

項目一覧はグラフの2,000ノードの表示上限と独立し、辞書全体を対象にします。
1ページ50行で、検索語・種類・名前順／IRI順を選べます。同名の項目は完全なIRIで区別し、
名称を押すと詳細が開きます。「参照のみ」の行は、定義がない参照先であることを明示します。
件数は絞り込み後の本当の総数です。辞書や条件を変えると先頭ページへ戻ります。

一覧の名称等は200文字まで表示し、省略を明示します。完全な内容は詳細で確認できます。
IRI自体は短く書き換えません。APIの一覧応答は256KiBまでで、収まらない場合は件数を隠して
行を落とす代わりに、理由と再試行の案内を返します。

## 編集して保存する

ライブラリは閲覧用、プロジェクトは編集用です。ライブラリのカードメニューから
プロジェクトへコピーするか、新規プロジェクトを作ります。

プロジェクトの項目一覧で名称を押すと、既存の編集フォームを使えます。各言語の名称や
定義を変更し、ヘッダーのUndo／Redoで戻す・やり直す操作ができます。保存状態を確認し、
「保存」を押してください。インポートやスナップショット由来の項目は従来どおり読み取り専用です。
一覧表のセルを直接書き換える形式ではありません。

検証・推論済みの結果は、表示言語を変えても再実行せずに名称を読み替えます。
取り込み完了レポートも、実行時の件数・行番号を保持したまま名称を読み替えます。
編集履歴の名称は操作時点の記録を保ち、説明文は現在のUI言語で表示します。
第三者エラー等の原文は「詳細」に保持します。

## 配布と後続の範囲

「About」の本体MIT・出典表示を保持しています。製品ビルドでは、実際に同梱された依存物の
通知もAboutから開けます。[配布物別の通知](distribution-notices.md)を参照してください。

文書ZIPに生成するサイト本文は現行どおり英語です。ZIPは原本ファイルを含むため、
内部データを除去した公開版として扱わないでください。公開用API・公開版生成はP3の計画です。
タグExcel／組織JSONの専用読み込みは、入力形式が固まるP5まで後回しにしています。
既存のCSV／Excel取り込みは従来の2,000行上限を維持します。
