# P3 公開版の使い方

公開版は、編集チームが内容を確認した配布用の版です。「承認」はインターネットへの一般公開ではありません。
P3はローカルDockerで確認できます。実Googleの設定や外部サーバー構築は、この開発の前提ではありません。

## レビューと承認

1. team版で編集用プロジェクトを開き、ヘッダーの「公開版」を押します。
2. 編集者または管理者が、出典とデータの利用条件を入力して「プレビューを作成」を押します。
3. 含まれる項目・statement数、除外された件数を確認します。「全出力をダウンロードして確認」で全ファイルを確認してください。
4. 管理者が、全出力と利用条件を確認したチェックを入れ、「版を承認」を押します。
5. 承認済み一覧からパッケージをダウンロードします。配布先への取り込みと切り替えは別の明示操作です。

閲覧者は承認済みの版を取得できます。編集者はプレビューまで、管理者だけが承認できます。
プレビュー以降に辞書や入力が変わった場合は、プレビューを作り直してください。
失効・競合・一時障害で出典や利用条件の入力を失いません。再ログイン時は以前のレビュー確認を無効にします。

キーボードではTabで各操作へ進み、Enter/Spaceでボタンや確認を操作できます。
フォーカス枠、処理状況と拒否の通知、Escapeでの終了と元の操作へのフォーカス復帰を用意しています。UI言語は日英で切り替えられます。

## どの内容が含まれるか

初期の `dictionary-v1` は、プロジェクトのmodel文書の受理済み正本から許可述語を抽出します。
書式Save前の確定編集も含みますが、フォームに入力しただけの未送信内容は含みません。
imports、shapes、データスナップショット、推論結果、Libraryは対象外です。
内部コメント、元JSON、未知の述語、空白ノードを含むstatementは含みません。
許可述語の値にも内部情報が含まれ得るため、自動的な匿名化や公開許諾とみなさないでください。

RDFのIRI、言語タグ、型とliteralの元の文字列を保持します。同じ名前でIRIが違う項目を統合しません。
初期の上限は入力model 100,000 statements、パッケージZIPと展開後合計それぞれ50 MiBです。超過すると部分版を作らず拒否します。

ZIPにはmanifest、Turtle、型付きJSON、データのLICENSE、出典NOTICEの5ファイルだけが入ります。
内部backupやプロジェクトZIPは別物です。それらを配布パッケージとして使わないでください。

## 版を固定する

承認済み版は編集・プロジェクト削除・通常Undoで変わりません。承認そのものはUndoできません。
削除済みプロジェクトの版はAPIで引き続き取得できます。ヘッダー入口は現存プロジェクト向けです。
サービスには版IDを指定します。配布のcurrentを切り替えても、版IDに固定した利用側は自動で切り替わりません。
ローカル配布・切り戻しは[運用手順](p3-local-operations.md)を参照してください。
